Privacy

Last updated 3 November 2026.

This website

This site sets no cookies, runs no analytics and loads nothing from other companies: the fonts and images are served from here. The host (GitHub Pages) keeps short-lived server logs, including IP addresses, for security; see GitHub's privacy statement.

Email

If you write to robin@leastlikelyai.com, your message and address are used only to reply to you, and aren't shared or added to any list.

Newsletter and YouTube

The newsletter is run on Substack, and the videos are on YouTube. When you use them, their own privacy policies apply.

Least Likely Tools (Google API access)

"Least Likely Tools" is a small private app that the channel's owner uses to read the Least Likely channel's own YouTube statistics and analytics. It asks Google only for read-only access to YouTube data. It has no other users, it runs only on the owner's computer, and the data it reads stays there: it isn't sold, shared, or used for advertising.

Least Likely Tools' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed at any time at myaccount.google.com/permissions.
